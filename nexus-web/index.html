About Mi9-Nexus

Mi9-Nexus is a local 1.7B reasoning assistant. It can use tools to compute, search your corpus, and search the web — the model decides when to call them. Each chat is auto-named and has its own sandbox.

Tools it can use

run_pythonRuns Python in a sandbox for arithmetic, logic, and data wrangling.
retrieveSearches the local corpus (docs, code, playbooks).
web_searchSearches the live web.
web_fetchReads a web page's text.

Controls

Deep thinkingModel reasons step-by-step before answering (slower, better on hard problems).
CreativityTemperature — higher = more varied, lower = more focused/repeatable.
LengthMax tokens per reply — longer answers take more time.

Tips

Ask it to use a tool for anything precise (arithmetic, code, facts). It shows each tool call and result inline. Enter sends, Shift+Enter adds a newline.
